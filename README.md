# WeatherApp ☀️🌧️

A simple, responsive weather application built with **HTML**, **CSS**, and **JavaScript**. 
It fetches real-time weather data from the [OpenWeatherMap API](https://openweathermap.org/) and displays it in a user-friendly interface.

---

## 🔍 Features

- Search for weather by city name
- Display of temperature, humidity, wind speed, and weather description
- Weather icons based on conditions
- Clean and responsive UI
